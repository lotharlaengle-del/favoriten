# Favoriten — Startseite

Eigene Favoritenverwaltung als Browser-Startseite für PC und Handy.
Dieses Repository enthält **nur den Seitencode**, keinerlei Daten.

Die Favoriten liegen in einer privaten Datei im Google Drive des Nutzers und
werden über ein eigenes Apps Script abgeglichen.

> Hier niemals `favoriten-daten.js` oder `favoriten-master.json` einchecken.
